# Week 12: Book Class

## Overview

This assignment turns Week 12 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

## Objectives

- Design private fields and a constructor.
- Initialize each object's data.
- Provide getters and a useful object method.

## Complete these steps

- Create Week12BookClass and a class named BookDemo.
- Copy the starter into BookDemo.java.
- Keep title and pages private.
- Initialize both fields in the constructor.
- Complete getTitle, getPages, and describe.
- Make describe return the title followed by a space-hyphen-space and the page count, such as Charlotte's Web - 192 pages.
- In main, create Charlotte's Web with 192 pages and The Hobbit with 310 pages.
- Print both descriptions and print the title of the book with more pages using a comparison.
- Run and confirm both descriptions and Longer book: The Hobbit appear.
- Submit BookDemo.java.

## What will be checked

Use this list as your final review before submitting.

- Book has private title and pages fields.
- The constructor initializes both fields.
- Getters and describe return useful object information.
- Two Book objects are created and compared by page count.
- The submitted file contains no unfinished TODO marker from the starter template.
