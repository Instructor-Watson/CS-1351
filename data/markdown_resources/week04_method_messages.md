## Overview

This assignment turns Week 4 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

- Define and call void methods.
- Keep each method focused on one job.
- Run a predictable check case.

## Complete these steps

- Create Week04MethodMessages and a class named MethodMessages.
- Copy the starter into MethodMessages.java.
- Do not move the three method declarations inside main.
- In printWelcome, print Welcome to Java!
- In printCourse, print CS 1351
- In printGoodbye, print Keep practicing!
- In main, call printWelcome(), then printCourse(), then printGoodbye().
- Run the program and verify the three lines appear in that order.
- Submit MethodMessages.java.

## What will be checked

Use this list as your final review before submitting.

- Three void methods besides main are defined.
- All three methods are called from main.
- The requested messages appear in the requested order.
- The submitted file contains no unfinished TODO marker from the starter template.
