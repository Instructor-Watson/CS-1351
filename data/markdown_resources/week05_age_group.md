## Complete these steps

- Create Week05AgeGroup and a class named AgeGroup.
- Copy the starter into AgeGroup.java.
- Prompt for an age and read an int.
- If age is less than 13, print Child.
- Otherwise, if age is less than 20, print Teen.
- Otherwise, print Adult.
- Run with 12 and confirm Child.
- Run with 13 and 19 and confirm Teen.
- Run with 20 and confirm Adult.
- Submit AgeGroup.java.

## What will be checked

Use this list as your final review before submitting.

- Scanner input and an if/else-if/else chain are used.
- Age 12 is classified as Child.
- Ages 13 and 19 are classified as Teen.
- Age 20 is classified as Adult.
- The submitted file contains no unfinished TODO marker from the starter template.
