# Personal Project Presentation Guide

Record a clear 5-10 minute presentation. Show the running program and explain your own design decisions; do not spend the presentation reading source code line by line.

## Recommended sequence

### 1. Purpose and user - about 30-60 seconds

- State the project title.
- Explain the problem and intended user.

### 2. Design - about 1-2 minutes

- Summarize the program's main workflow.
- Identify the important methods and the data stored by the array or ArrayList.
- For Part 2, explain what changed after Part 1.

### 3. Demonstration - about 2-4 minutes

- Start the program from a fresh run.
- Demonstrate the complete main workflow.
- Show one normal example.
- For Part 2, show invalid input being rejected and accepted after the user corrects it.
- For Part 2, show an empty collection or explain how the program handles it.

### 4. Java concepts - about 1-2 minutes

- Part 1: identify the decision, logical and relational operators, loop, methods, and array and explain what each does.
- Part 2: identify the String manipulation, loop-based validation, and collection processing and explain what each adds.

### 5. Closing - about 30 seconds

- State what works now.
- Mention one limitation, approved fallback, or future improvement.

## Delivery checklist

- The presentation lasts 5-10 minutes.
- The sequence is easy to follow.
- Text and program output are readable.
- Narration is understandable and focused.
- The complete workflow is visible.
- Required concepts are connected to their purpose, not merely named.
- Long pauses, unrelated material, and line-by-line code reading are avoided.
