# Week 10: Personal Project Part 1

## Overview

This assignment turns Week 10 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

## Objectives

- Combine foundational Java skills in one working program.
- Explain design choices and demonstrate the program.
- Package a complete project another person can run.

## Project work week

No new Think Java chapter is assigned for this project milestone.

## Complete these steps

- Review your approved proposal and instructor feedback before changing the project scope.
- Create an IntelliJ project named PersonalProject and use OpenJDK 26.
- Use PersonalProjectPart1.java as the main class; additional Java classes are allowed.
- Implement a simple version that starts, accepts input, performs its main purpose, and produces useful output.
- Use variables, console input and output, an if/else-if/else decision, at least one relational operator, at least one logical operator, and at least one loop.
- Define and call at least two methods besides main.
- Create and use at least one array.
- Use clear names, consistent indentation, and meaningful comments where the purpose is not obvious.
- Test the project from a fresh run and correct any errors that prevent its main workflow from finishing.
- Follow PROJECT_README_CHECKLIST.md when adding README.md with exact OpenJDK 26 and IntelliJ run instructions plus one example interaction.
- Follow PROJECT_PRESENTATION_GUIDE.md when recording a 5-10 minute presentation that explains the design, demonstrates the main workflow, and identifies the Java concepts used.
- Submit every Java source file, README.md, and the presentation in the locations specified by your instructor.

## What will be checked

Use this list as your final review before submitting.

- 20 points: the prototype runs and completes its main purpose.
- 10 points: readable organization and naming.
- 10 points: meaningful comments.
- 5 points each: flow control, logical operators, relational operators, a loop, two methods, and an array.
- 15 points: the presentation explains the design, demonstrates the complete workflow, and identifies required Java concepts.
- 15 points: the presentation follows a clear sequence, stays within 5-10 minutes, and is easy to understand.
- The submitted file contains no unfinished TODO marker from the starter template.
