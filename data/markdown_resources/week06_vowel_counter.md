# Week 6: Vowel Counter

## Overview

This assignment turns Week 6 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

## Objectives

- Traverse a String with a loop.
- Use charAt and length.
- Accumulate a count.

## Complete these steps

- Create Week06VowelCounter and a class named VowelCounter.
- Copy the starter into VowelCounter.java.
- Prompt for one word and read it with nextLine().
- Convert the word to lowercase.
- Use a for loop from 0 up to, but not including, word.length().
- Use charAt(i) to get the current character.
- Increase vowels when the character is a, e, i, o, or u.
- Print Vowels: followed by the count.
- Run with education and confirm Vowels: 5.
- Run with rhythm and confirm Vowels: 0.
- Submit VowelCounter.java.
