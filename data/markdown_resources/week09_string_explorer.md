# Week 9: String Explorer

## Overview

This assignment turns Week 9 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

## Objectives

- Call methods on immutable String objects.
- Store returned String values.
- Compare original and transformed values.

## Complete these steps

- Create Week09StringExplorer and a class named StringExplorer.
- Copy the starter into StringExplorer.java.
- Keep original set to Java is fun.
- Create uppercase by calling original.toUpperCase().
- Create replaced by calling original.replace("fun", "powerful").
- Print Original, Uppercase, and Replaced on labeled lines.
- Print original one more time to show it still contains Java is fun.
- Run and compare all four lines.
- Submit StringExplorer.java.

## What will be checked

Use this list as your final review before submitting.

- toUpperCase and replace are used.
- The original and two transformed values are stored separately.
- The original value is printed unchanged.
- The submitted file contains no unfinished TODO marker from the starter template.
