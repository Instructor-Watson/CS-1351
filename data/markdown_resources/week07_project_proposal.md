# Week 7: Personal Project Proposal

## Overview

This assignment is a project-planning milestone. Start from ProjectProposal.md, complete every section, and use the checklist before submitting.

## Objectives

- Choose an achievable project idea.
- Connect the idea to Java skills learned by Week 7.
- Define a testable Part 1 prototype and realistic Part 2 improvements.

## Required reading - one new chapter

- [Think Java Chapter 7 - Arrays and References](https://chrismayfield.github.io/ThinkJava2/ch07.html)

## Optional supplemental reading - previously covered chapters

- [Chapter 4 - Methods and Testing](https://chrismayfield.github.io/ThinkJava2/ch04.html)
- [Chapter 5 - Conditionals and Logic](https://chrismayfield.github.io/ThinkJava2/ch05.html)
- [Chapter 6 - Loops and Strings](https://chrismayfield.github.io/ThinkJava2/ch06.html)

## Complete these steps

- Read PROJECT_PLANNING_GUIDE.md and review PROJECT_PROPOSAL_EXAMPLE.md before drafting.
- Download or copy the ProjectProposal.md template and replace every TODO.
- Give the project a clear working title.
- In 2-4 sentences, explain the problem the program will solve and who will use it.
- Choose your own approved idea or adapt one of these: personal data manager, text-based game, educational quiz or flashcards, or a simple task helper that works locally.
- Describe the exact Part 1 workflow from program start through final output.
- Explain where your Part 1 will use console input/output, variables, an if/else-if/else decision, relational and logical operators, a loop, at least two methods, and an array.
- List at least three specific example inputs and the expected result for each.
- Describe the String manipulation, loop-based validation, and collection use you expect to add or strengthen in Part 2.
- List the Java files you currently expect to create.
- Write a week-by-week plan for Weeks 8, 9, 10, and 11-15.
- Identify at least two possible difficulties and a smaller fallback scope for each.
- Proofread the proposal and submit ProjectProposal.md or an instructor-approved PDF/DOCX version.
- Wait for instructor approval before substantially expanding the project scope.

## What will be checked

Use this list as your final review before submitting.

- 10 points: clear title, purpose, and intended user.
- 20 points: a specific, achievable Part 1 workflow.
- 25 points: every required foundational Java concept is mapped to a concrete project feature.
- 20 points: Part 2 improvements address strings, loop-based validation, and collections.
- 15 points: example inputs, expected results, files, and timeline are complete.
- 10 points: risks and fallback plans keep the project achievable.
- The submitted file contains no unfinished TODO marker from the starter template.
