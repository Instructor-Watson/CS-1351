# Week 7: Score Summary

## Overview

This assignment turns Week 7 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

## Objectives

- Declare and traverse an array.
- Accumulate a total.
- Track a maximum and calculate an average.

## Complete these steps

- Create Week07ScoreSummary and a class named ScoreSummary.
- Copy the starter into ScoreSummary.java.
- Keep the provided scores array unchanged.
- Set total to 0 and highest to scores[0].
- Use one loop to visit every score.
- Add each score to total.
- Update highest when the current score is larger.
- After the loop, calculate average as a double.
- Print Total, Average, and Highest on labeled lines.
- Run and confirm total 433, average 86.6, and highest 92.
- Submit ScoreSummary.java.

## What will be checked

Use this list as your final review before submitting.

- An int array and loop are used.
- The total is 433.
- The average is 86.6.
- The highest score is 92.
- The submitted file contains no unfinished TODO marker from the starter template.
