# Java personal project

The personal project lets you design a small program around an interest or practical need. Choose an achievable console application such as a local data manager, text-based game, quiz or flashcard tool, or another instructor-approved idea. The program must work locally and must not require a paid service or private account.

## Milestones

- Week 7 - Proposal: define the user, workflow, Java feature map, examples, files, schedule, and fallback scope. Obtain approval before substantially changing scope.
- Week 10 - Part 1: submit a simple functional prototype using foundational Java syntax, decisions, operators, loops, methods, and an array. No other assignment is due that week.
- Week 15 - Part 2: expand the prototype with meaningful String manipulation, loop-based input validation, and collection processing.

For Parts 1 and 2, submit every Java source file needed to run the project, a README with exact OpenJDK 26 and IntelliJ instructions, and the required presentation. Missing required files may prevent the project from being evaluated.
