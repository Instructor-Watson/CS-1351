# Personal Project README Checklist

Submit README.md with both project parts. Another student should be able to run the project by following only this file.

## Required sections

### Project title and purpose

- State the project name.
- Explain in 2-3 sentences what the program does and who it helps.

### Required files

- List every Java file needed to compile and run the project.
- Identify the file that contains main.

### Requirements

- State that the project uses OpenJDK 26 and IntelliJ IDEA.

### Run instructions

1. Open IntelliJ IDEA.
2. Open the submitted project folder or create a Java project and copy the required files into src.
3. Select OpenJDK 26 as the project JDK.
4. Open the class containing main.
5. Use the green Run triangle and select the class's main method.

Add any project-specific setup step after these instructions. Do not assume the reader knows which class to run.

### Example interaction

- Show at least one exact user input and the important output it produces.
- For Part 2, also show one invalid input and the helpful prompt that follows.

### Known limitations

- Briefly list any approved limitation or fallback scope.
- Write “None known” if the required workflow is complete.

## Final README check

- All filenames and class names match the submitted files exactly.
- The JDK version is 26.
- The run steps start from a clean IntelliJ session.
- Example input/output matches the current program.
- No TODO text or outdated Part 1 instruction remains.
