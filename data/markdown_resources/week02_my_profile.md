# Week 2: My Profile

## Overview

This assignment turns Week 2 concepts into a small, finishable Java program or project milestone. Start from the provided template, preserve the public class filename, and run the program in IntelliJ before submitting.

## Objectives

- Declare String, int, and double variables.
- Use an arithmetic operator.
- Combine labels and variable values in output.

## Complete these steps

- Create a new IntelliJ project named Week02MyProfile using OpenJDK 26.
- Under src, create a Java class named MyProfile.
- Copy the starter into MyProfile.java.
- Replace the empty name with your first name.
- Choose a whole-number favoriteNumber.
- Choose a decimal favoritePrice.
- Calculate doubledNumber by multiplying favoriteNumber by 2.
- Print four labeled lines: name, favorite number, doubled number, and favorite price.
- Run the program and confirm every label has a value.
- Submit MyProfile.java.

## What will be checked

Use this list as your final review before submitting.

- String, int, and double variables are used.
- The favorite number is multiplied by 2.
- All four requested labeled lines are printed.
- The submitted file contains no unfinished TODO marker from the starter template.
