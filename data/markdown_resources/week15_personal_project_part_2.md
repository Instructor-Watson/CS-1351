## Complete these steps

- Copy your working Part 1 project into a new IntelliJ project or a clearly labeled Part 2 folder before making changes.
- Keep the original purpose working while adding the requirements below.
- Review LOOP_BASED_INPUT_VALIDATION_GUIDE.md before implementing validation.
- Use meaningful String manipulation that changes, searches, formats, or analyzes project text.
- Use a loop to keep asking until at least one important user input is valid, and display a helpful prompt after invalid input.
- Use an array or ArrayList to store and process the project's related data.
- Preserve the foundational Part 1 requirements unless your approved design makes one unnecessary and your instructor approves the change.
- Test the complete project from a clean start, including invalid input and an empty collection.
- Follow PROJECT_README_CHECKLIST.md when updating README.md with every required file, exact OpenJDK 26 and IntelliJ run steps, and sample input/output.
- Follow PROJECT_PRESENTATION_GUIDE.md when recording a 5-10 minute presentation that explains the design changes, demonstrates the full workflow, and identifies the Java concepts used.
- Submit all Java files, README.md, and the presentation in the locations specified by your instructor.
